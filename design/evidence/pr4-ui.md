# 칸 관리 실제 앱 관찰

2026-10-14, macOS 26.5.2 / Apple Silicon, 릴리스 앱. CUA AX와 화면을 직접 관찰했다. 이 파일은 대화의 스크린샷에 대한 관찰 기록이며 이미지 파일이 아니다.

- 4칸 → `⌘⌥→` → `⌘⇧R`: 이름 필드에 `터미널 2`가 선택돼 있었다. `서버 · 한글 이름`으로 변경하고 `⌘T`를 누르자 두 번째 칸에 실제 셸이 열렸다. 포커스 경계는 해당 칸 하나에 표시됐다.
- 해당 셸에서 `export CHOP_ZOOM=kept; sleep 2; printf 'BACKGROUND_FINISHED\n'`를 실행하고 왼쪽 빈 칸으로 이동해 확대했다. 한 칸이 전체 작업 영역을 채웠다.
- 복귀 후 두 번째 칸으로 이동하니 `BACKGROUND_FINISHED` 출력이 있었다. `printf 'ZOOM=%s\n' "$CHOP_ZOOM"` 결과는 `ZOOM=kept`였다.
- 아래 왼쪽 빈 칸의 닫기를 누르자 아래 오른쪽 칸이 전체 아래 행을 채웠다. 위 두 칸과 실행 셸은 유지됐다.
- 헤더에 추가한 중첩 버튼 스택이 늘어나며 버튼이 왼쪽에 모이는 회귀를 관찰했다. 스택을 평탄화해 기존 12pt 간격으로 수정했다. 새 빌드의 4칸 화면에서 확대/닫기가 각 헤더 오른쪽 끝에 정렬된 것을 확인했다.
- 긴 한국어 이름으로 변경하고 창 오른쪽 아래를 드래그해 약 644×442pt의 전체 창으로 줄였다. 긴 이름은 말줄임되고 버튼 2개가 겹치지 않았다. 경로 전체와 이름 전체는 툴팁/AX에 남는다. 중앙 추가와 편집 버튼도 보였다.

통합 테스트도 숨긴 셸의 지연 명령 완료, 확대 전후 동일 surface 소유 view, 레이아웃 불변, 실행 칸 제거 거절, 마지막 빈 칸 보존을 검증했다. 전체 VoiceOver 탐색은 수행하지 않았다.
