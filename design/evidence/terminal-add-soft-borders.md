2026-10-20 Codex 셀프 리뷰. 외부 리뷰나 승인이 아니다.
사용자는 직전 양옆 선이 너무 강하며 파일 트리 왼쪽 경계와 붙어 두껍게 보인다고 교정했다.
오른쪽 자체 선은 파일 트리가 보일 때 숨기고 기존 native resize divider를 함께 쓴다.
트리가 닫혔을 때만 자체 오른쪽 선을 표시한다. 왼쪽 선은 유지하고 자체 두 선의 색은
light DEDEDE / dark3D3D3D의 옅은 무채색으로 낮췄다. 폭48pt/버튼32pt/inset8pt/선1pt는
유지한다. 이전 B9BDC6/555B67과 오른쪽 중복 선은 현재 계약을 대체하지 않는다.

실제 앱: 별도 ChopWidthVerification 세션의 AppKit 앱을 다시 빌드해1100×752px
라이트 격자/트리 표시, 다크 탭/트리 숨김, 다크 탭/트리 재표시를 직접 판독했다.
트리 표시 시 새 선+native divider가 겹치던2pt 경계가 사라지고 기본 파일 트리 선만
남았다. 숨김 시 영역 오른쪽에1pt 선이 돌아왔으며 두 모드 자체 선의 대비가 낮아졌다.
